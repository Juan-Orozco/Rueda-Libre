# Rueda Libre - Tienda de bicicletas

Sitio web de una tienda de bicicletas, hecho con HTML, CSS, Bootstrap y Tailwind CSS. Muestra el catálogo de bicicletas y accesorios con un diseño responsive que se adapta a celular, tablet y computador.

🛠️ Tecnologías
HTML5: estructura semántica de las páginas
CSS3: estilos personalizados
Bootstrap
Tailwind CSS

✨ Funcionalidades
Página de inicio con [banner / carrusel de bicicletas destacadas]
Catálogo de productos en tarjetas
Menú de navegación responsive
Formulario de Inscripcion
Cards con los tipos
Sección de contacto
